## 流量池机制：多机器用户的福音

ISIF Cloud有个很贴心的设计——流量池机制。简单说就是，同系列不同地域的产品可以共享流量。

比如你同时买了香港的CO系列和日本的CO系列，两台机器的流量是可以合并计算的。假设香港机器只用了500GB，日本机器用了1500GB，那么总共消耗的是2000GB，只要不超过两台机器的总流量包，就不会产生额外费用。
